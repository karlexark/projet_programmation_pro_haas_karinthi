Décrire une image

Choisissez une image sur votre appareil. Vous pouvez aussi poser une question à son sujet. L'application vous décrit son contenu.

Format JPEG ou PNG, 10 mégaoctets au maximum.

Par exemple : « Quelle est la date de péremption ? ». Sans question, vous obtenez une description générale.

Si vous utilisez déjà un lecteur d'écran, vous pouvez décocher cette case : il annoncera la description lui-même.
